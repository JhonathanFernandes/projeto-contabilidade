# Projeto Contabilidade

Site institucional inicial para uma profissional que atua nas áreas contábil e jurídica.

## Conceito visual
- Estrutura institucional com apresentação, áreas de atuação, perfil e contato.
- Direção visual editorial, com tons naturais, tipografia serifada e detalhes dourados.
- Animações de entrada com Framer Motion e GSAP/ScrollTrigger.
- Parallax no hero e layout responsivo.

## Executar localmente
```bash
npm install
npm run dev
```

## Personalização pendente
Antes de publicar, substituir:
- Nome/marca e monograma provisórios.
- Biografia, formação, OAB/CRC e áreas efetivamente atendidas.
- Retrato profissional autorizado.
- E-mail, telefone, WhatsApp e links sociais.
- Imagens por fotografias próprias/licenciadas.

Os textos atuais são conteúdo demonstrativo e não afirmam credenciais profissionais.
